# Acceptance Matrix

Authority: `docs/requirements.md` defines all normative requirements. This document operationalizes those requirements for cross-phase use while remaining subordinate to the governing two-document contract formed by `docs/requirements.md` and `docs/reference_standards.md`.
Repository-local instruction files may be consulted for implementation discipline, but no row in this matrix may rely on them as the deciding authority for documentary-phase contract closure.

Layer A = blocking acceptance gate. Layer B = supporting quality check.
